# 현장 투입 전 장비 검증

아래 항목은 장비 조합별 현장 검증 체크리스트다. 통과 결과를 기록할 때는 iPadOS·앱 빌드·카메라 펌웨어·케이블과
프린터 모델·펌웨어·용지 종류를 함께 적는다. 카메라나 프린터 설정이 바뀌면 해당 검증을 반복한다.

## 1. 설치 환경

필수 설치는 Xcode와 해당 iPad를 지원하는 iOS/iPadOS 플랫폼 파일이다. SwiftUI·ImageCaptureCore·UIKit 인쇄는
Apple SDK에 포함된다. CocoaPods, Homebrew, XcodeGen, Sony Creators’ App, 프린터 제조사 전용 앱, 서버는 필요 없다.
시뮬레이터는 선택 사항이며 USB 카메라/프린터 검증을 대신하지 못한다.

현재 Mac은 macOS 15.8.1이므로 [공식 호환표](https://developer.apple.com/xcode/system-requirements)의
Xcode 26.3(macOS 15.6 이상) 설치 경로를 사용할 수 있다. 최신 Xcode가 더 새 macOS를 요구하면
[Apple 개발자 다운로드](https://developer.apple.com/download/all/)에서 호환 버전을 고른다.
단, 연결한 iPad의 OS가 해당 개발 환경에서 지원되는지 확인한다. 필요하면 macOS와 Xcode를 함께 갱신한다.

설치 후 Xcode → Settings → Accounts에 본인 Apple 계정을 추가한다. iPad를 Mac에 연결하고 신뢰·개발자 모드를 허용한다.
무료 서명은 7일 후 만료되므로 행사 날짜 전에 갱신한다. 서명 준비에는 인터넷이 필요할 수 있다.

## 2. 가장 먼저: USB 한 장

1. 프린터는 아직 연결하지 않는다. iPad와 A7 IV를 데이터 USB-C 케이블로 연결한다.
2. 카메라를 정지사진·단일 촬영·AF-S 또는 AF-C·JPEG 전용·Dest.+Camera·Original·USB Remote Shooting으로 설정한다.
3. 버튼을 누르지 않고 케이블 연결만으로 장비 패널에 모델·펌웨어·라이브뷰·촬영 준비 완료가 나오는지 확인한다. 연결 중 셔터가 작동하지 않아야 한다.
4. 현장 검증을 위해 진단 도구의 JPEG 점검 촬영 1장을 누른다(매 연결의 필수 단계는 아님). 실제 셔터가 한 번만 작동하고 SD 카드에도 사진이 남는지 확인한다.
5. 테스트 미리보기에 방금 찍은 피사체가 보이는지 확인한다. 촬영 전에 고유 번호를 피사체에 표시하면
   오래된 RAM 이미지와 혼동하는 것을 잡을 수 있다.
6. 진단 기록에 JPEG 바이트 수·전송 소요 시간·저장 성공이 남는지 확인한다. 썸네일만 온 것을 원본 성공으로 보지 않는다.
7. 장면을 바꿔 10회 반복한다. 누락·중복·잘못된 순서·파일 잘림이 있으면 다음 단계로 넘어가지 않는다.
8. AF-C · AF w/ Shutter On · Priority Set in AF-C Release로 설정한다. 렌즈를 가려 초점 실패를 만들어도
   카운트다운 뒤 촬영을 계속하는지 확인한다. 촬영·취소 후 반셔터가 풀리는지 확인한다.
   촬영 화면이 가로·세로 모두 스크롤 없이 크게 표시되며 큰 숫자와 중단 버튼이 잘리지 않는지 확인한다.
9. 카메라 연결 시 장비 패널에 실제 피사체의 라이브뷰가 나타나는지 확인한다. 촬영을 시작하고 피사체를
   움직여 카운트다운 배경이 갱신되는지 확인한다. 셔터 직전 1초와 원본 수신 중의 정지 표시는 정상이다.
   화면을 받지 못하면 새 촬영을 하지 않아야 한다. 일반 사진 JPEG와 라이브뷰 프레임이 섞이지 않는지도 확인한다.

실패 시 기록할 것: OS/펌웨어, 마지막 opcode와 응답 코드, 카메라 화면의 USB 모드·저장 설정,
실제 셔터 작동 여부, SD 원본 존재 여부. 사진·카메라 시리얼·Wi-Fi 암호를 공개 로그에 넣지 않는다.

## 3. 8장과 일정

1. 데모 표시가 없는지 확인한다. 시작 시각과 실제 셔터 시각을 영상 또는 독립 시계로 측정한다.
2. 첫 촬영 전 10초, 이후 10초 주기의 목표 일정과 허용 오차를 현장에서 결정·기록한다.
   OS와 카메라가 하드 실시간을 보장한다고 가정하지 않는다.
3. 매 장 고유 번호를 달리해 8장의 순서·중복·누락·디코딩을 확인한다. 최소 10세션(80장) 반복한다.
4. 전송 시간이 10초를 초과하는 설정에서 다음 촬영이 무리하게 이어지지 않고 중단되는지 확인한다.
   해당 장비 조합이 주기를 유지하지 못하면 운영 조건을 충족하지 못한 것으로 판정한다.

## 4. 중단과 복구

| 주입할 장애 | 기대 동작 |
| --- | --- |
| 카운트다운 중 케이블 분리 | 촬영 중단, 기존 JPEG 유지, 재연결 후 자동 준비, 미확인 촬영은 수동 복구 |
| 셔터 직후 USB 분리 | 미확인 촬영 남음, 자동 셔터 재시도 없음 |
| JPEG 수신 타임아웃 | USB 세션 무효화, 물리적 재연결 요구, 늦은 콜백 무시 |
| 앱 비활성/잠금 | 진행 작업 중단, 재개 전 상태 확인, 백그라운드 촬영 없음 |
| JPEG 저장 후 앱 강제 종료 | 저장된 영수증 또는 pending의 로컬 파일로 복구, 이전 사진을 재촬영하지 않음 |
| RAW/HEIF 설정으로 변경 | 파일 형식 또는 디코딩 검증에서 정지, 잘못된 결과를 사진으로 집계하지 않음 |
| 카메라 RAM에 이전 이미지 남김 | 새 촬영 거절, 수신 복구를 통해 운영자가 이전 파일 확인 |
| 로컬 저장 공간 부족 | 셔터 전 영수증 저장에 실패하면 촬영하지 않음; 수신 후 실패하면 pending 유지 |

수신만 복구해도 파일이 없으면 SD 카드 원본을 확인한다. 카메라 RAM의 파일을 어느 세션 것으로 볼지
판단할 수 없을 때는 새 관람객에게 노출하지 않고 운영자가 직접 정리한다. 앱이 카메라 SD 파일을 삭제하지 않는다.
이 개발판에는 SD에서 특정 파일을 선택해 가져오는 UI가 없다. 필요한 원본은 별도로 보존한 뒤 재시작한다.

## 5. 선택·합성·인쇄

1. 가로 화면에서 8장이 스크롤 없이 4열×2행으로 보이고, 네 장 선택 후에도 나머지 사진 밝기가 유지되는지 확인한다. 8장 중 4장을 고른다. 고른 순서가 프레임 좌상→우상→좌하→우하 순서와 일치하는지 확인한다. 한 장을 해제하고 다른 사진을 고르면 마지막에 추가되는지 본다.
2. 가로 3:2 원본의 좌우 각각 약 5.56%가 잘리고 상하가 유지되는지 확인한다. 라이브뷰·선택·확대 구도가 실제 촬영 후 합성과 일치하는지 확인한다. EXIF 방향·비율이 다른 원본은 회전과 중앙 crop을 따로 확인한다.
3. 의림제 PNG 프레임으로 1800×1200 가로 결과를 확인한다. 프레임 선택 메뉴가 없는지, 이전 포레스트 세션의 사진·선택·인쇄 상태를 유지하고 의림제 프레임으로 다시 합성하는지 확인한다.
4. 프린터 Other → Direct Connection 모드에 iPad를 미리 연결한다. 인터넷이 끊겨 있어도 JPEG 수신과 인쇄가 되는지 확인한다.
5. 앱에서 인쇄를 누르고 시스템 시트에서 AirPrint 지원 프린터, 사용 가능한 용지, 매수를 확인한다. 용지가 여러 개면 이미지 비율에 가까운 용지가 선택되는지 확인한다. 실제 출력물의 순서·색·여백·재단을 확인한다.
6. 시스템 인쇄 취소, 프린터 전원 끔, 용지 없음/걸림을 각각 확인한다. 앱이 미리보기를 보존하고 자동 재전송하지 않아야 한다.
7. 인쇄 창을 띄운 채 앱 종료 후 복원한다. 이전 인쇄 결과가 불명확하다는 안내와 재인쇄 확인이 떠야 한다.
8. 새 관람객을 누르면 이전 세션 파일이 삭제되고 새 화면에 과거 사진이 보이지 않아야 한다.

통과 기록이 채워지기 전에는 관람객용 운영 승인을 의미하지 않는다.

## 6. 자동 연결

- 앱을 먼저 연 뒤 케이블 연결, 케이블을 먼저 연결한 뒤 앱 실행, 분리·재연결을 각각 확인한다.
- 자동 연결 도중 케이블을 빼고 다시 꽂아도 이전 연결의 결과가 새 연결을 준비 완료로 표시하면 안 된다.
- 사진 선택·합성·인쇄 작업 중 재연결하면 작업 완료 후 준비되어야 한다. 자동 연결은 촬영을 시작하지 않는다.
- JPEG 점검 촬영을 하지 않고 새 관람객의 첫 사진을 촬영·수신할 수 있어야 한다.
- 미확인 촬영 기록이 있으면 자동 준비 후에도 새로운 촬영은 막고 수신 복구 버튼만 사용한다.
- 권한을 거부했거나 카메라 설정이 잘못되면 오류와 재시도 동작을 확인한다. USB 시간 초과는 계속 물리적 재연결이 필요하다.

## 7. 화면 방향 (기본 가로)

- 카메라와 iPad를 가로로 설치한다. 라이브뷰 방향은 원본이 기본이다. 위/왼쪽/오른쪽 표식이 있는 피사체로 상하좌우가 촬영 JPEG와 일치하는지 확인한다.
- 앱을 이전 세로 버전에서 업데이트하면 최초 실행 후 원본 방향이 선택되는지 확인한다. 이후 수동으로 방향을 바꾸면 앱 재실행 후 유지되어야 한다.
- 세로 사용이 필요한 경우 장비 설정의 왼쪽/오른쪽 회전을 선택한다. EXIF로 이미 세로 해석된 프레임은 다시 회전하지 않아야 한다.
- 가로 iPad에서 원본 8장이 스크롤 없이 4열×2행으로 보이고 확대·선택·해제가 되는지 확인한다.
- 6×4 가로 합성물의 사진 칸이 692×519 px(4:3), 칸 간 가로·세로 간격이 24 px이고 오른쪽 제목과 겹치지 않는지 확인한다. 실제 AirPrint 용지 방향과 출력물 재단을 별도로 확인한다.
