# iPad 포토부스

USB 카메라로 8장을 촬영하고, 선택한 4장을 프레임에 합성해 AirPrint로 인쇄하는 iPad 앱이다.
행사명·안내 문구·인쇄 템플릿은 운영자가 iPad에서 바꿀 수 있다. 저장한 설정은 앱을 다시 열거나 새 촬영을 시작해도 유지된다.

**현재 카메라 구현은 Sony A7 IV(ILCE-7M4)를 대상으로 개발되었다.** 코드에서도 해당 모델만 허용한다.
다른 Sony 모델이나 다른 제조사의 카메라는 지원하지 않으며, 사용하려면 별도 드라이버 구현과 실기기 검증이 필요하다.
프린터는 특정 제조사나 모델로 제한하지 않고 **AirPrint 지원 프린터**를 사용한다.

SwiftUI·ImageCaptureCore·UIKit으로 구현했으며 외부 패키지·서버·유료 API에 의존하지 않는다.
설치 후 촬영·합성은 오프라인으로 동작한다. 인쇄에는 iPad와 프린터가 서로 통신할 수 있는 네트워크가 필요하다.

## 지원 범위

| 항목 | 현재 범위 |
| --- | --- |
| iPad | iPadOS 18 이상, iPad 전용 앱. 개발·설치에 사용한 장비는 iPad Pro 13인치(M4) |
| 카메라 | Sony A7 IV / ILCE-7M4, USB Remote Shooting / PC Remote |
| 촬영 파일 | JPEG. RAW·HEIF 촬영 흐름은 지원하지 않음 |
| 프린터 | iPad의 시스템 인쇄 화면에서 검색되는 AirPrint 지원 프린터 |
| 프레임 | 가로 3:2 PNG, 사진 네 칸의 위치와 4:3 비율은 고정 |
| 최종 파일 | 7500×5000px JPEG, 화면 미리보기는 긴 변 최대 3200px |

실기기 설치·실행, 시뮬레이터 화면, 모의 USB 응답, 이미지 합성·설정 복원 검증을 진행했다.
이 결과가 모든 펌웨어·케이블·프린터 조합의 현장 동작을 보장하지는 않는다.
사용할 장비로 [현장 검증 절차](docs/hardware-validation.md)를 확인한다.

## 설치

1. Mac에 Xcode 26 이상과 해당 iPad를 지원하는 iOS/iPadOS SDK를 설치한다. Swift 6.2 이상이 필요하다.
2. `PhotoBooth.xcodeproj`를 열고 `PhotoBooth` scheme을 선택한다.
3. Signing & Capabilities에서 Team과 Bundle identifier를 본인 계정에 맞게 설정한다. Team을 로컬 파일로 관리하려면 `Config/Signing.local.xcconfig.example`을 `Config/Signing.local.xcconfig`로 복사해 값을 입력한다. 이 파일은 Git에서 제외된다.
4. iPad의 잠금을 풀고 Mac을 신뢰한 뒤 개발자 모드를 켠다.
5. 실행 대상으로 iPad를 선택하고 `⌘R`로 빌드·설치한다. 최초 설치·서명 준비에는 인터넷이 필요할 수 있다.
6. 앱이 요청하는 카메라 제어·콘텐츠 접근 권한을 허용한다.

Xcode에서 네트워크 기기 연결이 준비되어 있으면 이후 설치는 무선으로도 가능하다.
현장 운영 중에는 Mac이 필요 없다. 카메라를 iPad에 연결하고 프린터 네트워크를 준비하면 된다.
무료 Apple Personal Team 서명은 만료 후 재설치가 필요하므로 행사 전에 유효 기간을 확인한다.

## 촬영과 인쇄

1. 카메라를 연결하고 운영 설정에서 촬영 준비 상태와 라이브뷰를 확인한다.
2. **촬영 시작**을 누르면 10초 간격으로 총 8장을 촬영한다.
3. 인쇄할 사진 4장을 선택한다. 선택 순서가 좌상 → 우상 → 좌하 → 우하 배치 순서다.
4. **선택 완료**를 눌러 합성물을 확인한다. 필요하면 **사진 다시 선택**으로 돌아간다.
5. **인쇄**를 누르고 시스템 화면에서 프린터·용지·매수를 확인한다.
6. 출력물을 확인한 뒤 **새 촬영**으로 다음 촬영을 준비한다. 이때 이전 촬영 사진은 삭제된다.

데모는 USB 카메라 없이 화면 흐름을 확인하는 용도이며 인쇄는 비활성화된다.
실제 카메라 촬영이나 프린터 연결 검증을 대신하지 않는다.

### 카메라 준비: Sony A7 IV

- 정지사진·단일 촬영·JPEG로 설정한다. AF-S와 AF-C를 처리하며 앱이 초점 모드를 자동 변경하지 않는다.
- Remote Shoot Setting은 `Dest.+Camera`, 전송 크기는 `Original`로 설정해 SD 카드에도 원본을 남긴다.
- USB 연결은 `Remote Shooting` / `PC Remote`를 사용한다. USB Streaming이나 Mass Storage가 아니다.
- 데이터 전송 가능한 USB-C 케이블을 사용하고 카메라는 별도로 전원을 공급한다. USB Power Supply는 OFF로 설정한다.
- 초점 미확인 상태에서도 셔터 작동을 우선하려면 카메라의 AF-C, AF w/ Shutter On, AF-C 우선순위 Release 설정을 확인한다.

연결 시 USB 세션과 라이브뷰를 자동으로 확인한다. 진단용 JPEG 촬영은 운영 설정에서 수동으로 실행한다.
라이브뷰 수신이 실패하면 새 촬영을 진행하지 않으며, 사진 전송이 촬영 간격을 넘기면 중단한다.
중단 후 재개는 남은 사진에 대해 새 10초 카운트다운으로 시작한다.

### 프린터 준비: AirPrint

특정 프린터 모델이나 제조사 전용 앱을 요구하지 않는다. 단순히 Wi-Fi가 되는 프린터가 아니라 **AirPrint를 지원하는 프린터**여야 한다.
iPad와 프린터를 같은 네트워크에 연결한다. 프린터 자체 Wi-Fi에 직접 연결할 경우에도 해당 연결 모드에서 AirPrint 검색이 가능해야 한다.
연결 방법은 사용하는 프린터의 설명서를 따른다. [Apple의 AirPrint 안내](https://support.apple.com/ko-kr/109349)를 참고한다.

앱은 프린터가 제공한 용지 목록에서 완성 이미지의 비율에 가장 가까운 용지를 우선 선택한다.
비율이 같으면 6×4인치 사진 크기에 가까운 용지를 우선한다. 6×4 용지가 없어도 제공된 다른 용지로 인쇄할 수 있다.
용지 목록과 출력 가능 영역은 프린터 드라이버가 결정하며, 실제 여백·재단·색상은 출력물로 확인해야 한다.

시스템의 인쇄 완료 콜백은 종이가 실제로 나온 사실을 보장하지 않는다.
앱은 인쇄를 자동 재전송하지 않는다. 결과가 불명확하면 출력물을 확인한 뒤 재인쇄한다.

## 운영자 커스터마이징

화면 위 **운영 설정 → 커스터마이징**에서 편집하고 **저장**을 누른다.
각 입력칸에는 항목명과 실제 표시 위치 설명이 있으며, 선택 항목은 비워 숨길 수 있다.
운영 설정의 진단 기록은 펼쳐 볼 수 있고 최신 항목부터 표시한다. 오픈소스 고지도 같은 화면에서 확인할 수 있다.

| 항목 | 적용 위치 |
| --- | --- |
| 상단 이름 | 화면 왼쪽 위와 프린터 작업 이름 |
| 시작 제목 | 촬영 시작 화면의 큰 제목. 줄바꿈 가능 |
| 시작 안내 | 시작 제목 아래, 촬영 시작 버튼 위 |
| 촬영 중 안내 | 카운트다운 화면 왼쪽 아래 |
| 완료 화면 제목 | 완성 화면의 인쇄 버튼 위 |
| 템플릿 PNG | 시작 화면의 예시 이미지와 최종 인쇄 프레임 |

**PNG 가져오기**는 iPad 파일 선택 화면을 연다. 선택한 PNG는 앱 내부로 복사하므로 원래 파일이 없어져도 사용할 수 있다.
저장한 문구와 PNG는 앱 종료·재실행·업데이트와 새 촬영 후에도 유지된다. 취소하면 편집 내용을 적용하지 않는다.
**기본값 불러오기** 후 저장하면 포함된 의림제 문구와 프레임으로 돌아간다.

설정 변경 시 촬영 원본·사진 선택·인쇄 상태는 보존한다. 이전 설정으로 만든 합성물은 다시 만들어야 한다.
방문객 화면에는 프레임 선택 메뉴를 두지 않고 운영자가 저장한 템플릿 하나를 사용한다. 시작 화면의 예시는 사진 칸에 회색 배경과 ①~④ 번호를 표시해 배치 순서를 안내한다.

### PNG 제작 규격

- 가로 3:2, 사진 네 칸은 투명 영역으로 남긴 PNG.
- 최소 1800×1200px, 권장 7500×5000px, 최대 40MB. 이미지 크기 제한은 15000×10000px 이내, 총 7500만 픽셀 이하다.
- 사진 칸 위치·크기는 고정이다. 배경·문구·로고·장식은 자유롭게 디자인할 수 있으며, 사진 칸 안의 장식은 사진 위를 덮는다.

Illustrator에서 **1800×1200px 설계 좌표**로 작업할 때 사진 크기는 각각 **692×519px(4:3)**이며,
아트보드 왼쪽 위를 원점으로 한 중심점은 다음과 같다.

| 사진 위치 | 중심 X | 중심 Y |
| --- | ---: | ---: |
| 왼쪽 위 | 415 | 328.5 |
| 오른쪽 위 | 1131 | 328.5 |
| 왼쪽 아래 | 415 | 871.5 |
| 오른쪽 아래 | 1131 | 871.5 |

왼쪽·위쪽·아래쪽 마진은 각각 69px, 사진 사이 가로·세로 간격은 24px다.
7500×5000px 아트보드로 직접 작업한다면 위 수치를 모두 `25/6`배 한다.
최종 JPEG는 항상 7500×5000px로 합성하며, 설계 좌표와 실제 출력 픽셀을 구분한다.

라이브뷰·사진 선택·확대·합성에는 중앙 4:3 크롭을 적용한다. 가로 3:2 원본은 좌우 각각 약 5.56%가 잘린다.
EXIF 방향을 반영하며 촬영 원본 JPEG 자체는 변경하지 않는다. 라이브뷰와 촬영 원본의 구도 차이는 실기기로 확인한다.

## 데이터 보존과 복구

- 촬영 JPEG는 디코딩·바이트 수·중복을 확인하고 원자적으로 저장한 뒤 성공으로 센다.
- 셔터 전 미확인 촬영 영수증을 저장한다. 실패나 앱 종료 후 영수증이 남으면 자동 재촬영하지 않는다. 운영 설정에서 수신 복구와 SD 카드 원본을 확인한다.
- 연결 해제·타임아웃은 카메라 세션을 무효화한다. 앱이 비활성화되면 진행 중 촬영을 멈춘다.
- 현재 촬영 세션과 선택·합성물은 복원한다. 사진 보관함에 쓰거나 외부 서버로 전송하지 않는다.
- `Application Support/BoothSessions`는 촬영 데이터, `Application Support/BoothCustomization`은 운영자 설정과 PNG를 보관한다. 촬영 데이터는 iCloud 백업에서 제외한다.
- 새 촬영은 이전 촬영 세션만 지우고 운영자 설정은 유지한다. 앱을 삭제하면 로컬 사진과 설정도 삭제된다.

## 개발과 검증

```sh
# 핵심 규칙·세션 및 커스터마이징 저장 시험
swift test --jobs 2

# Swift Testing 모듈이 없는 Command Line Tools 환경의 대체 실행
./scripts/check-core.sh

# 백그라운드 ImageCaptureCore 콜백 회귀 확인(macOS)
./scripts/check-camera-callbacks.sh

# 부팅된 iOS 시뮬레이터에서 UIKit/ImageIO 합성·크롭·AirPrint 용지 선택 검증
./scripts/check-image-orientation.sh

# 서명 없는 시뮬레이터 빌드
xcodebuild -project PhotoBooth.xcodeproj -scheme PhotoBooth \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

| 경로 | 역할 |
| --- | --- |
| `Sources/BoothCore` | PTP 패킷, Sony A7 IV 촬영 흐름, 세션·커스터마이징 저장, 템플릿 규칙 |
| `PhotoBooth/Camera` | USB 검색·권한·세션·직렬 명령과 수신 |
| `PhotoBooth/App` | 촬영 일정·화면 상태·설정 적용·복원 |
| `PhotoBooth/Imaging` | EXIF 처리·크롭·7500×5000 JPEG 합성 |
| `PhotoBooth/Printing` | 제조사와 무관한 AirPrint, 용지 선택·취소·완료 처리 |
| `PhotoBooth/Views` | 촬영·선택·미리보기·운영 설정 UI |

USB 제어는 공개 구현을 참고한 실험적 구현이며 Sony 공식 인증 드라이버가 아니다.
[조사 기록](docs/feasibility.md), [장비 검증 절차](docs/hardware-validation.md), [참고 구현·라이선스 고지](Licenses/NOTICE.md)를 함께 확인한다.
